# 🍽️ Hesap bölüştürücü

Herkesin masaya bıraktığı para toplanır ve kişi sayısına bölünür. Toplam tam bölünmezse artan lira, listedeki ilk kişilere birer lira yazılır.

500 TL ve 3 kişi: paylar 167, 167 ve 166 TL. 500 TL'yi tek başına ödeyen kişi 333 TL alacaklıdır.

`hesap_bolusturucu_v2.py` alacağı ödemeye çevirir. Borçlu, alacaklıyla eşleşir:

- Mehmet → Ayşe: 167 TL
- Zeynep → Ayşe: 166 TL

```bash
python3 hesap_bolusturucu/hesap_bolusturucu.py
python3 hesap_bolusturucu/hesap_bolusturucu_v2.py
```

# 🎯 Sayı tahmin

Bilgisayar 1 ile 100 arasında bir sayı tutar. Her tahminden sonra sayı daha büyük mü, daha küçük mü söylenir. Doğru tahminde kaç deneme sürdüğü yazılır.

`sayi_tahmin_v2.py` geçersiz yazıyı geri çevirir, tahminleri tabloda tutar ve tur bitince yeniden oynamayı sorar.

`random`, tutulan sayıyı 1 ile 100 arasından seçmek için kullanılır.

```bash
python3 sayi_tahmin/sayi_tahmin.py
python3 sayi_tahmin/sayi_tahmin_v2.py
```
